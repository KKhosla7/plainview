# Plainview 1.2.0

**Plainview turns raw Markdown, JSON, XML, YAML, TOML, CSV/TSV and log files into readable documents in Chrome and Firefox.**

## What it does

- **Markdown** — GFM/CommonMark, Contents panel, title/lede box, code copy, tables, task lists, math and Mermaid diagrams.
- **JSON / JSONC** — searchable, collapsible tree with comments, trailing commas, JSONPath and JMESPath queries.
- **XML** — element tree with attributes, text, CDATA, comments, search and XPath.
- **YAML and TOML** — collapsible trees with search and copy.
- **CSV / TSV** — virtualized tables with search, filters, sorting and column controls.
- **Swagger / OpenAPI** — structured JSON or YAML views.
- **Logs** — wide, readable monospace views.
- **HTML and Source views**, per-document view and reading-position memory.
- **Light and Dark themes**, content zoom, syntax-highlighted source and Copy source.
- **Search and queries** across data formats.
- **Clean exports** — native data, filtered results, selected content or a self-contained HTML reader.
- **Settings** for theme, tree font size, escaped strings, indent guides, tables and exports.
- **Update notice** with a one-time release-notes link.

## 1.2.0 highlights

- Added YAML, TOML, CSV/TSV, logging and Swagger/OpenAPI views.
- Added JSONPath and JMESPath queries, XML XPath, search and filtering.
- Added virtualized JSON, XML and CSV rendering for large files.
- Added selected-content and filtered-data exports.
- Moved XML parsing and XPath into the extension service worker.
- Added immediate loading feedback for large XML files.

- Added a full JS, CSS and policy AST gate and an in-process packaging path.

## Install

### Chrome / Chromium

1. Download `plainview-chrome-1.2.0.zip` and unzip it.
2. Open `chrome://extensions` → Developer mode → **Load unpacked** → select the unzipped folder.
3. Open Plainview → Details → enable **Allow access to file URLs**.
4. Open a supported local file.

### Firefox

1. Download `plainview-firefox-1.2.0.zip`.
2. For HTTP(S) documents, load it temporarily from `about:debugging#/runtime/this-firefox`.
3. For local `file://` documents, sign/install it permanently through AMO, then enable
   `about:addons` → Plainview → Permissions → **Access your data for file:// URLs**.
4. Firefox uses its native JSON viewer for `application/json`; other supported formats use Plainview.

### Source

`plainview-1.2.0-source.zip` contains the full source at the `v1.2.0` tag.

## Known limits

- Raw HTML in Markdown is shown as text, not executed. MDX/JSX is not evaluated.
- JSON/XML trees stop at 40,000 nodes; source highlighting stops at 1.5 MB.
- Firefox uses its native JSON viewer rather than Plainview's tree.
- Firefox temporary add-ons cannot read `file://` documents.
- A forced download (`Content-Disposition: attachment`) must be opened locally.
