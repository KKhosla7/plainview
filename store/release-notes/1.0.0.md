# Plainview 1.0.0

**Plainview turns raw Markdown, JSON and XML files into readable documents in Chrome and Firefox.**
Open a local file or a supported URL and Plainview replaces the browser's plain-text view with a
reader.

## What it does

- **Markdown** — GFM/CommonMark rendering, Contents panel, title/lede box, code copy, tables,
  task lists and Mermaid diagrams.
- **JSON / JSONC** — collapsible tree, comments and trailing commas, expand/collapse and copy.
- **XML** — collapsible element tree with attributes, text, CDATA and comments.
- **HTML and Source views** — the selected view is remembered per document.
- **Reading position** — remembered per document across reloads.
- **Light and Dark themes** — remembered; no Auto mode.
- **Content zoom** — scales the rendered type without changing browser zoom.
- **Source view** — syntax highlighting, full width and Copy source.
- **Download** — saves the original file as-is.
- **Settings** — optional “Open supported downloads in Plainview” and OS file-association help.
- **Update notice** — a one-time notification with a link to the release notes.

Plainview renders locally. There is no analytics, telemetry, remote code or remote font loading.

## 1.0.0 highlights

- First stable release.
- Every-page payload reduced to a ~3 KB loader and a ~28 KB stylesheet. The ~116 KB reader bundle
  is loaded only for detected Markdown/JSON/XML documents; Mermaid and fonts remain lazy.
- One-time update notification and NEW toolbar badge.
- Firefox setup documented: temporary add-on for HTTP(S), signed permanent install and
  `file://` permission for local files.
- Firefox’s native JSON viewer documented.
- Gitleaks scans the full history and working tree in CI.
- Release assets include Chrome, Firefox and source ZIPs.

## Install

### Chrome / Chromium

1. Download `plainview-chrome-1.0.0.zip` and unzip it.
2. Open `chrome://extensions` → Developer mode → **Load unpacked** → select the unzipped folder.
3. Open Plainview → Details → enable **Allow access to file URLs**.
4. Open a `.md`, `.json` or `.xml` file.

### Firefox

1. Download `plainview-firefox-1.0.0.zip`.
2. For HTTP(S) documents, load it temporarily from `about:debugging#/runtime/this-firefox`.
3. For local `file://` documents, sign/install it permanently through AMO, then enable
   `about:addons` → Plainview → Permissions → **Access your data for file:// URLs**.
4. Firefox uses its native JSON viewer for `application/json`; Plainview handles Markdown and XML.

### Source

`plainview-1.0.0-source.zip` contains the full source at the `v1.0.0` tag.

## Known limits

- Raw HTML, MDX/JSX, YAML and TOML are not rendered.
- JSON/XML trees stop at 40,000 nodes; source highlighting stops at 1.5 MB.
- A forced download (`Content-Disposition: attachment`) must be opened locally.
- Firefox uses its native JSON viewer rather than Plainview’s tree.
- Firefox temporary add-ons cannot read `file://` documents.
