# Plainview 1.2.3

## Fixes

- Improved the 16 px extension icon so the toolbar shows the P< mark instead of collapsing to a plain P.
- Includes the 1.2.2 fixes:
  - Firefox false XML source-change prompt.
  - Duplicate source watchers after automatic refresh.
  - Automatic setup guide after installation.
  - Large XML loading progress bar.
  - Corrected P< icon at larger sizes.

## Install

### Chrome / Chromium

1. Download `plainview-chrome-1.2.3.zip` and unzip it.
2. Open `chrome://extensions` → Developer mode → **Load unpacked** → select the unzipped folder.
3. Open Plainview → Details → enable **Allow access to file URLs**.

### Firefox

1. Download `plainview-firefox-1.2.3.zip`.
2. For HTTP(S) documents, load it temporarily from `about:debugging#/runtime/this-firefox`.
3. For local `file://` documents, sign/install it permanently through AMO, then enable
   `about:addons` → Plainview → Permissions → **Access your data for file:// URLs**.

### Source

`plainview-1.2.3-source.zip` contains the full source at the `v1.2.3` tag.
