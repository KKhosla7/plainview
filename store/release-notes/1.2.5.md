# Plainview 1.2.5

## Fixes

- Fixed Firefox treating the Buy Me a Coffee control as a native draggable link.
- The coffee icon now drags smoothly with its thread instead of dragging the link ghost/page.
- Normal clicks still open Buy Me a Coffee.
- Includes the finalized 7A icon and the 1.2.4 fixes.

## Install

### Chrome / Chromium

1. Download `plainview-chrome-1.2.5.zip` and unzip it.
2. Open `chrome://extensions` → Developer mode → **Load unpacked** → select the unzipped folder.
3. Open Plainview → Details → enable **Allow access to file URLs**.

### Firefox

1. Download `plainview-firefox-1.2.5.zip`.
2. For HTTP(S) documents, load it temporarily from `about:debugging#/runtime/this-firefox`.
3. For local `file://` documents, sign/install it permanently through AMO, then enable
   `about:addons` → Plainview → Permissions → **Access your data for file:// URLs**.

### Source

`plainview-1.2.5-source.zip` contains the full source at the `v1.2.5` tag.
