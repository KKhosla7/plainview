# Plainview 1.2.1

## Fixes

- Fixed false “Source changed” prompts for XML files in Firefox.
- Fixed duplicate source watchers after an automatic refresh.
- Restored the setup guide opening automatically after installation.
- Replaced the emoji coffee icon with one inline icon that looks the same in Chrome and Firefox.
- Fixed dragging the coffee icon so releasing it no longer opens the Buy Me a Coffee page.

## Install

### Chrome / Chromium

1. Download `plainview-chrome-1.2.1.zip` and unzip it.
2. Open `chrome://extensions` → Developer mode → **Load unpacked** → select the unzipped folder.
3. Open Plainview → Details → enable **Allow access to file URLs**.

### Firefox

1. Download `plainview-firefox-1.2.1.zip`.
2. Load it temporarily from `about:debugging#/runtime/this-firefox` for HTTP(S) testing.
3. For local `file://` documents, sign/install it permanently through AMO, then enable
   `about:addons` → Plainview → Permissions → **Access your data for file:// URLs**.

### Source

`plainview-1.2.1-source.zip` contains the full source at the `v1.2.1` tag.
