# Plainview 1.2.6

## Fixes

- Renamed the source-change action from **Reload** to **Refresh**.
- Refresh now updates the reader using the already fetched XHR source instead of reloading the browser page.
- Refresh is offered only when the fetched source differs from the rendered source.
- Auto-refresh follows the same content comparison and does not run for unchanged files.
- Includes the corrected `plainview@kkhosla7.github.io` Firefox extension ID.

## Install

### Chrome / Chromium

1. Download `plainview-chrome-1.2.6.zip` and unzip it.
2. Open `chrome://extensions` → Developer mode → **Load unpacked** → select the unzipped folder.
3. Open Plainview → Details → enable **Allow access to file URLs**.

### Firefox

1. Download `plainview-firefox-1.2.6.zip`.
2. For HTTP(S) documents, load it temporarily from `about:debugging#/runtime/this-firefox`.
3. For local `file://` documents, sign/install it permanently through AMO, then enable
   `about:addons` → Plainview → Permissions → **Access your data for file:// URLs**.

### Source

`plainview-1.2.6-source.zip` contains the full source at the `v1.2.6` tag.
