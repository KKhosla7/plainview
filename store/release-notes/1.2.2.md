# Plainview 1.2.2

## Fixes

- Fixed the Firefox XML source-change false positive caused by the early loader adding an attribute to the raw XML root.
- Fixed duplicate source watchers and repeated remounting after automatic refresh.
- Restored the setup guide opening automatically after installation.
- Added a visible progress bar while large XML files are loading.
- Updated the extension icon to the corrected P< mark.

## Install

### Chrome / Chromium

1. Download `plainview-chrome-1.2.2.zip` and unzip it.
2. Open `chrome://extensions` → Developer mode → **Load unpacked** → select the unzipped folder.
3. Open Plainview → Details → enable **Allow access to file URLs**.

### Firefox

1. Download `plainview-firefox-1.2.2.zip`.
2. For HTTP(S) documents, load it temporarily from `about:debugging#/runtime/this-firefox`.
3. For local `file://` documents, sign/install it permanently through AMO, then enable
   `about:addons` → Plainview → Permissions → **Access your data for file:// URLs**.

### Source

`plainview-1.2.2-source.zip` contains the full source at the `v1.2.2` tag.
