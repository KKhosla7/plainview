Downloads

Supported Markdown, JSON, XML, YAML, TOML and CSV/TSV downloads open in Plainview first. The download is cancelled and removed; use the reader's Download button when you want to save the original file.

Source changes

This is off by default. Without it, Plainview shows a prompt with Reload and Dismiss so a file change never replaces what you are reading unexpectedly.

Make your browser the default for file clicks

A browser extension cannot change OS file associations. Set the default app for these file types in your OS:

.md.markdown.json.jsonc.swagger.openapi.log.yaml.toml.csv.tsv.xml.rss.atom
Linux

Find the MIME type, then point it at your browser's desktop file.

xdg-mime query filetype README.md
ls /usr/share/applications | grep -E 'chrome|chromium|firefox'
xdg-mime default google-chrome.desktop text/markdown
xdg-mime default google-chrome.desktop application/json
xdg-mime default google-chrome.desktop application/xml

Use chromium-browser.desktop, chromium.desktop or firefox.desktop as appropriate. Do not point text/plain at the browser unless you want every text file to open there.

Windows

Settings → Apps → Default apps → Choose defaults by file type, then set .md, .json and .xml to Chrome or Firefox. If the browser is not listed, use “Open with” → “Choose another app” → “Look for another app” and select the browser executable.

macOS

Select a file in Finder → Get Info → Open with → choose Chrome or Firefox → Change All.

File access

Chrome: open chrome://extensions → Plainview → Details → enable Allow access to file URLs.

Firefox: install the signed add-on permanently, then open about:addons → Plainview → Permissions → enable Access your data for file:// URLs. Temporary add-ons loaded through about:debugging do not receive file access.
