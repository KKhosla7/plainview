Let Plainview open your files

    File access

    Local files only render after your browser grants Plainview access to file URLs.

    Chrome / Edge

    1. Open chrome://extensions or edge://extensions.
    2. Select Plainview → Details.
    3. Enable Allow access to file URLs.

    Firefox

    1. Install the signed add-on permanently.
    2. Open about:addons → Plainview → Permissions.
    3. Enable Access your data for file:// URLs.

    Temporary add-ons loaded through about:debugging do not receive file access.
