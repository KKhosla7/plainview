Let Plainview open your files

    Downloads

    When Chrome or Firefox downloads a supported file, Plainview opens it in the reader instead of leaving a raw download behind. This is expected behavior, not a failed download.

    Use the reader’s Export action to save the original file or a standalone HTML copy. The same guidance is available in Settings → Downloads.
