Setup guide

Let Plainview open your files

    File access

    Chrome / Edge: open chrome://extensions or edge://extensions → Plainview → Details → enable Allow access to file URLs.

    Firefox: install the signed add-on permanently, then open about:addons → Plainview → Permissions → enable Access your data for file:// URLs. Temporary add-ons loaded through about:debugging do not receive file access.

    Recommended settings

    Open Settings to tune the reader after setup.
